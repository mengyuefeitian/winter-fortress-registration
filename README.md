# 无尽冬日管理助手

> 为《无尽冬日》联盟活动打造的一站式报名管理小程序 —— 堡垒、兵工厂、峡谷会战、国战、官职，五种活动一个入口；成员活跃度自动统计，告别 Excel 表格和群里刷屏报名。

## 为什么需要它

联盟活动一多，报名管理很快就会失控：谁报了、报满没、谁是替补、谁该踢掉重新分配……全靠人工翻聊天记录、手动数表格，费时又容易出错。

到了每周活跃统计更是麻烦：管理层要在群里挨个点名，人工核对谁今天上线了，跨天还得重新来一遍。

**无尽冬日管理助手** 把这一切搬进小程序：成员自助报名，管理员实时看到报名/满员状态；用户一打开小程序就自动登记当日活跃，管理层打开就能看到本周整周的活跃表，一键截图存档。

## 核心功能

### 报名管理

- 🏰 **五种活动全覆盖**：堡垒、兵工厂、峡谷会战、国战、官职报名，一个小程序全搞定
- 👥 **分角色管理**：普通用户 / 盟管 / 区管 / 超级管理员，权限逐级细分，各管一摊
- 🗂 **多分区 / 多联盟**：分区与联盟数量不限，多区管协同管理
- ✅ **在线申请与审核**：想当盟管/区管？在线提交申请，超管一键审核通过
- 📊 **实时报名状态**：满员自动置灰，容量可按活动类型自定义，谁在排队一目了然
- 📈 **数据统计与截图**：管理员随时查看统计数据，一键截图保存到相册

### 联盟活跃

- 📅 **自动登记活跃**：用户打开小程序即自动标记当日活跃，无需管理层手动点名
- 🔗 **归属自动识别**：按"最后一次报名选择的联盟"判定归属，老用户也能自动回溯补登
- ✅ **双列表勾选**：今日活跃 / 未活跃两个列表互相迁移，2–3 列自适应铺满屏幕
- 🖼 **周活跃表截图**：导出 8 列表格（成员 + 本周 7 天），活跃打勾、未活跃打叉，未来日期留空
- 🧭 **区管总览**：一张表看全分区各联盟本周每天的活跃人数，点联盟名可下钻管理

### 运维与通知

- 🔔 **审核结果通知**：申请结果、报名状态变化，微信订阅消息直接推送到用户
- 🧹 **自动清理**：过期报名、失效时间段、超期审批记录定时自动清空，无需人工维护

## 使用指南

### 普通用户

1. 首页选择自己所在分区
2. 选择想报名的活动（堡垒 / 兵工厂 / 峡谷会战 / 国战 / 官职）
3. 填写昵称与位置信息即可完成报名
4. 在【我的】→【我的报名】中随时查看或取消已报名的活动

> 只要通过任意活动报名成功并选择过联盟，系统就会记住你的归属，之后每天打开小程序自动登记为当日活跃。

### 盟管 / 区管 / 超级管理员

- **盟管**：管理所绑定联盟的活动配置与报名数据，查看统计并截图；在【联盟活跃】中登记与导出成员活跃
- **区管**：创建分区、配置联盟与各类活动、审核盟管申请、管理成员；在【联盟活跃】总览中查看全分区各联盟本周活跃人数
- **超级管理员**：审核区管申请、管理超管名单、查看全局统计、必要时清空数据

权限从普通用户开始逐级申请：想管理联盟就申请盟管，想管理整个分区就申请区管，均需上级审核通过后生效。

## 技术架构

| 层级 | 说明 |
|------|------|
| 前端 | 微信小程序原生框架（WXML / WXSS / JS），无第三方 UI 库 |
| 后端 | 微信云开发 —— 云数据库 + 云函数（Node.js）+ 定时触发器 |
| 权限 | 分级角色模型，敏感读写一律收口到云函数（绕开客户端 20 条查询上限与集合写权限限制） |
| 统计截图 | 离屏 Canvas 2D，两遍计算高度的绘制法，避免长列表被截断 |

### 云函数

| 云函数 | 职责 |
|--------|------|
| `login` | 登录与用户初始化 |
| `register` | 堡垒报名与取消 |
| `manageTimeSlot` / `manageZone` | 时间段与分区配置 |
| `manageBattle` / `manageArsenal` / `managePosition` | 国战 / 兵工厂 / 峡谷与官职报名管理 |
| `manageAdmin` | 盟管、区管、分区开通三类申请的列表与审批 |
| `manageAllianceActivity` | **联盟活跃**：成员名单、周活跃记录、自动登记与过期清理 |
| `manageUserIdentity` / `manageFeedback` | 身份与反馈管理 |
| `sendReviewNotify` / `sendApplyEmail` / `sendFeedbackEmail` | 订阅消息与邮件通知 |
| `clearRegistrations` / `clearExpiredData` / `cleanupApplications` | 定时清理（含联盟活跃过期数据） |
| `getStatistics` | 统计数据聚合 |

## 部署自己的实例

1. 前往 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序并获取 AppID
2. 在微信开发者工具中打开项目，开通云开发，记录环境 ID
3. 把 `project.config.json` 的 `appid`、`miniprogram/app.js` 和 `miniprogram/cloudbaserc.json` 中的 `env` 换成你自己的环境 ID
4. 在云开发控制台创建数据集合
5. 在 `superAdmins` 集合中添加你的手机号，成为第一位超级管理员
6. 右键 `miniprogram/cloudfunctions/` 下每个云函数目录，选择「上传并部署：云端安装依赖」
7. 点击「上传」提交审核，通过后即可发布

### 数据集合

| 分类 | 集合 |
|------|------|
| 用户与权限 | `users`、`superAdmins`、`admins`、`settings` |
| 分区与联盟 | `zones`、`alliances` |
| 活动配置 | `timeSlots`、`battleConfigs`、`arsenalConfigs`、`canyonConfigs`、`positionConfigs` |
| 报名记录 | `registrations`、`battleRegistrations`、`arsenalRegistrations`、`canyonRegistrations`、`positionRegistrations` |
| 联盟活跃 | `allianceMembers`（持久成员名单）、`allianceActivity`（周活跃记录，仅保留本周） |
| 其他 | `feedbacks` |

> 版本号统一在 `miniprogram/utils/version.js` 中管理，上传新版本前记得更新。

### 关于定时清理

云函数的定时触发器**按函数独立注册**，且开发者工具中不可见，需到[网页版云开发控制台](https://mp.weixin.qq.com/)确认：

- `cleanupApplications` 的 timer 定义在 `config.json`（每日运行，清理 14 天前的已处理申请）
- `clearRegistrations` 的 hourly 触发器同时负责清理联盟活跃的过期周数据

若控制台触发器列表为空，函数不会自动运行——需重新部署或在网页版手动添加触发器。
